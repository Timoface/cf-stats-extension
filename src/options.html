CF Stats+

v2.0.2

Единая статистика решённых задач по архивам Codeforces и AtCoder

Расширение показывает графики прямо в профиле Codeforces. Здесь можно настроить вежливые задержки между запросами, срок жизни кэша и параметры сопоставления задач.

Как работает AtCoder-сверка. Задачи, решённые на Codeforces (в том числе в gym/тренировках), дополнительно сверяются с открытым архивом AtCoder Problems по названию. Посылки с самого AtCoder не загружаются.

Запросы к API

Очередь выполняет запросы строго по одному. Это снижает риск временной блокировки.

Задержка меньше 2000 мс повышает риск получить лимит или Cloudflare-блокировку.

Собирать посылки через HTML-страницы Основной режим v2.0: читает /submissions/handle/page/N с cookies браузера и видит посылки из закрытых групп. При ошибке автоматически используется публичный API.

Кэш

Архивы меняются редко, история посылок — чаще. Свежие данные подставляются из локального хранилища.

Сопоставление

Задача сначала ищется по официальному contest ID, затем по названию, затем нечётко.

Сверять с архивом AtCoder Только gym/тренировки, только уникальные выразительные названия. AtCoder-задачи не имеют тегов в архиве.
Нечёткое сопоставление с CF Ищет переименованные задачи по комбинации слов и символов. Консервативный порог, чтобы не было ложных совпадений.

Хранилище

Данные лежат только в chrome.storage.local и никуда не отправляются.

    О расширении

    CF Stats+ читает страницы посылок на codeforces.com с cookies текущей сессии (same-origin), поэтому видит в том числе закрытые группы. Архивы задач загружаются через официальный Codeforces API и открытый архив AtCoder Problems. Никакой сервер расширения не используется, аккаунты и пароли не запрашиваются.

    Разрешения: storage — локальный кэш; unlimitedStorage — архивы задач; доступ к codeforces.com и kenkoooo.com — для чтения HTML-посылок и JSON-архивов. Графики рисует локально встроенный Chart.js, удалённые скрипты не загружаются.
